# client/web

Klient som gör saker i E37:s webbgränssnitt som inte går via API:et, till exempel via inloggad session och deras interna endpoints, eller browser-automation om det krävs.

Använd bara för det som saknas i `client/api/`. Dokumentera varje funktion med vilken lucka i API:et den täcker, så att den kan tas bort när API:et hinner ikapp.

Fylls på när det är klart vilka luckor som behöver täckas.
